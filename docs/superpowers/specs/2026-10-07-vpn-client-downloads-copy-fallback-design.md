# Veltrix VPN: ссылки на приложения и надёжное копирование

## Цель

Сделать подключение понятным для нетехнического пользователя: дать прямые ссылки на рекомендованные клиенты для основных платформ и обеспечить копирование VPN-ссылки внутри Telegram, Nicegram и обычных браузеров.

## Интерфейс

- В разделе «Как подключиться» доступны пять платформ: iPhone, Android, Windows, macOS и Linux.
- Для каждой платформы показывается одно рекомендованное приложение и одна заметная ссылка на официальный источник загрузки:
  - iPhone — Happ в App Store;
  - Android — Happ в Google Play;
  - Windows, macOS и Linux — Hiddify на странице стабильного релиза.
- Платформы не делятся на «проверенные» и «непроверенные»: инструкция выглядит как единая релизная функция.
- После загрузки приложение предлагает пользователю скопировать ссылку Veltrix, импортировать её в клиент и включить VPN.
- Существующая визуальная система, мобильная компоновка и минимальный размер сенсорных целей сохраняются.

## Копирование ссылки

Общий `copyConnectionUri` остаётся единственной точкой копирования для главного экрана и карточки профиля:

1. Сначала используется стандартный `navigator.clipboard.writeText`.
2. Если API отсутствует или WebView отклоняет вызов, создаётся временное поле, текст выделяется и вызывается нативный `document.execCommand("copy")`.
3. Временное поле удаляется сразу после попытки, включая ошибочный путь; VPN-ссылка не остаётся в DOM и не попадает в логи.
4. Пользователь видит инструкцию по ручному копированию только тогда, когда оба способа не сработали.

Новые зависимости не добавляются.

## Совместимость

- Базовая функциональность не зависит от `color-mix`, `backdrop-filter` или других декоративных CSS-возможностей.
- Текущий облегчённый режим для старых iOS WebView сохраняется.
- Ссылки открываются как обычные HTTPS-ссылки в новой вкладке с безопасным `rel`.
- Основные элементы остаются доступными с клавиатуры и имеют сенсорную область не меньше 44 пикселей.

## Проверка

- Модульный тест подтверждает основной Clipboard API, резервное копирование и ошибку только при отказе обоих способов.
- Браузерный тест запускает кабинет без Clipboard API, проверяет успешное копирование через резервный путь и отсутствие VPN-ссылки в DOM после операции.
- Браузерный тест проверяет пять платформ, точные официальные URL и переключение инструкции.
- Выполняются полный набор frontend-тестов, production-сборка, проверка интерфейса Impeccable и браузерный QA на мобильной и настольной ширине.
